# PAV Evidence Navigator

Термины работы с документами и доказательствами.

## Язык

**Документ**:
Загруженный в библиотеку источник, текст которого доступен для поиска с указанием места в первоисточнике.

**Выбранные документы**:
Подмножество загруженных документов, по которым выполняется текущий поиск или исследование. Выбор документов для поиска отличается от выбора файлов для загрузки.

**Извлечённый текст документа**:
Текстовое содержимое всех страниц или записей документа, подготовленное для поиска. Его объём в символах отличается от размера исходного файла в байтах.
_Избегать_: размер файла как синоним объёма извлечённого текста.
