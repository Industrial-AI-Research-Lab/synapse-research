## Самопроверка перед завершением

Область — разница с копиями двух исходных файлов, сохранёнными перед этой задачей. Предыдущие незакоммиченные изменения сохранены. Контракты API, обработчики, типы и состояние не менялись.

1. **Входы.** Изменена статическая разметка в ветви `documents?.length` компонента DocumentsWorkspace. При непустом списке используется компактная кнопка, при пустом или отсутствующем списке — прежняя кнопка emptyState. Загрузка, ошибка, поиск и исследование не изменены. CSS: колонка ≤22.5rem — короткая подпись, >22.5rem — полная; coarse — минимум 2.75rem, прочие указатели — 2.25rem. Проверены реальные узкие и широкие колонки; coarse проверен по исходному правилу.

Опровергнуто областью селекторов: компактные размеры требуют documentPanel, а emptyState — соседняя ветвь вне article. Второй риск: два span озвучиваются дважды. Оба aria-hidden, а aria-label кнопки один; браузер показывает одно полное доступное имя.
3. **Неудобная проверка.** Окно 320px, короткая подпись, открытие Enter, закрытие и возврат фокуса — успешно. Постоянные тесты не добавлялись для локального визуального изменения.
