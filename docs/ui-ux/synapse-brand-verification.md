# Проверка бренда Synapse Research — 16.10.2026

Область проверки: изменения текущего запроса относительно состояния файлов перед заменой бренда. В рабочем дереве уже находился большой незакоммиченный редизайн; этот отчёт не является аудитом всего редизайна.

## 1. Входы и ветви

| Вход / состояние | Ветвь | Проверка |
| --- | --- | --- |
| Sidebar, isExpanded=false | Монограмма S.R, подписи пунктов через Tooltip | Chrome, 320 px; ширина ссылки 55 px, переполнения нет |
| Sidebar, isExpanded=true | Synapse / Research, текстовая навигация, недоступные пункты | Снимки Chrome 1440 и 320 px; 32 px Lora 400 / 23 px Lora Italic 400 |
| /documents и / | Активен пункт документов; точный маршрут и корень перечислены в Sidebar.tsx | /documents проверен браузером; / проверен чтением условия |
| /researches и /researches/:id | Активен пункт исследований | /researches проверен браузером; вложенный маршрут проверен чтением startsWith |
| Другой маршрут | Нет активного пункта; DisabledPage с новым брендом | /sources проверен браузером |
| Перезагрузка раскрытого меню | Сохранённое состояние из существующего ключа localStorage | Chrome: после reload доступна кнопка «Свернуть меню» |

Изменены только статическое содержимое Sidebar и DisabledPage, оформление бренда, favicon и head. Сигнатуры, типы, API и обработчики не изменялись. Массивы навигации и все их ветви прочитаны.

## 2. Предположение о возможной ошибке

Подозрение: `frontend/src/components/Sidebar/sidebar.module.scss:26` — три символа вместо одного не поместятся в узкую мобильную панель. Проверено на 320 px: scrollWidth ссылки не превышает clientWidth; S.R целиком виден на снимке.

Подозрение: `frontend/index.html:7` — браузер продолжит показывать старый favicon по прежнему адресу. Ссылка получила новый query-параметр; запрос возвращает 200 и новый SVG без буквы Ф.

## 3. Неудобный крайний случай

Проверены раскрытие, сворачивание и перезагрузка на 320 px. Отдельный автоматизированный тест в репозиторий не добавлялся: изменение статического брендинга проверено реальным браузером. Фавикон визуально просмотрен в размерах 16, 32 и 64 px.

## 4. Атомарность

Новых последовательностей чтение → проверка → запись нет. Существующий ключ `folio.sidebar.expanded` намеренно сохранён как внутренний идентификатор, чтобы не потерять настройку меню. Сетевые записи и внешние побочные действия не добавлялись.

## 5. Связанные файлы и подключение

`frontend/src/app/App.tsx` подключает Sidebar и выбирает DisabledPage; интерфейсы компонентов прежние. Доступные названия бренда обновлены. `aria-controls` и id навигации согласованы как research-navigation. Стили бренда находятся в существующем модуле Sidebar; Lora Regular и Italic уже подключены локально в global.scss. `frontend/index.html` ссылается на public/favicon.svg; после сборки dist/favicon.svg побайтно совпадает с исходным. Общие типы, библиотечные потоки и их очистка не менялись.

## 6. Имена

Новых идентификаторов с числовыми суффиксами или обозначениями New/Old/Copy/Temp нет. Новый research-navigation описывает существующую навигацию.

## 7. Соглашения

Новых или перемещённых компонентов нет. JSX остался в Sidebar.tsx и DisabledPage.tsx, оформление — в соседнем SCSS, цвета — через существующие токены. Favicon остаётся по существующему пути. Новых зависимостей в проект не добавлено.

## 8. Внешние ссылки

В изменённом коде не добавлены ссылки на тикеты, PR, планы или внешние документы.

## 9. Комментарии

Комментарии и сообщения журналирования в исходном коде не добавлялись и не менялись; проверка качества новых комментариев неприменима.

## 10. Что проверено и что не проверено

Проверено: lint, production build, git diff --check, detector Impeccable (пустой список), реальные размеры и начертания бренда, обе версии меню на 320 px и раскрытая на 1440 px, сохранение раскрытия после reload, активный пункт исследований, DisabledPage, загрузка и содержимое favicon, включение favicon в сборку.

В ходе финального аудита SVG пересохранён с LF вместо CRLF; git diff --check и сборка повторены. Геометрия SVG не менялась, поэтому снимки 16/32/64 остаются применимы. Изменения документации проверены чтением.

Не проверено: поведение кэша значков во всех браузерах и полный сценарий выполнения исследования — они не воспроизводились в этом запросе. Смена URL favicon снижает риск старого кэша. Работа сервера и API не менялась. Предшествующие изменения рабочего дерева не аудировались целиком.
