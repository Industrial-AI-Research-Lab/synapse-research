# Сверка пяти состояний с согласованными макетами

Сравнение выполнено с research-approvals.html (пять содержательных состояний), research-approval-page.html (композиция настоящей страницы) и research-approval-complete.html (полный открытый JSON). Последующие прямые уточнения пользователя имеют приоритет: не повторять вопрос, документы, названия и отчёт; сохранить полный JSON; использовать чернильные заголовки и оливковые действия; нижнюю ссылку сделать как в макете — с иконкой, приглушённым цветом и подписью «Открыть в Synapse».

## Пять состояний

| Состояние | Сверено и исправлено | Действия |
| --- | --- | --- |
| Запрос и документы | Один вопрос и один список источников на странице. При отличии снимка выводится только отличающаяся часть. Пояснение приглушённое, без повторной инструкции и декоративной статусной плашки. | «Подтвердить и продолжить», «Отклонить». |
| Структура данных | Текст пояснения как в макете страницы. Версия, проиндексированные документы и прочитанные фрагменты — три отдельных показателя. «Ограничения подготовки» располагаются перед материалами. Уже показанные документы и материалы не повторяются. | «Подтвердить структуру», «На доработку» при подтверждённом переходе назад. |
| Калькуляторы предложены | Название один раз, формула выделена шрифтом заголовков, описание отдельно, входы компактные: имя и единица в одной строке. Дополнительные поля и ограничения сохранены. Заголовок общей заметки — «Границы применения». | «Подтвердить калькуляторы», «На доработку» при подтверждённом переходе назад. |
| Калькуляторы не предложены | Сохранён текст про недостаточность данных. Каждый расчёт показан названием и исходной причиной, без повторных полей «Расчёт / Причина». Общая заметка называется «Результат проверки». | «Продолжить без калькуляторов», «На доработку» при подтверждённом переходе назад. |
| Публикация отчёта | Текст пояснения и заметка «После подтверждения» соответствуют макету. Сам отчёт показан один раз; ссылка ведёт к существующему результату. Подтверждён переход к #research-result и единственное вхождение тестового отчёта. | «Опубликовать отчёт», «Отклонить публикацию». |

Во всех состояниях сохранены открытые «Данные для решения» с прежними JSON, копированием и прокруткой. Убран добавленный ранее вывод технических названий следующих фаз: такие строки отсутствовали в согласованных блоках и повторяли пояснение. Название вторичного действия по-прежнему следует фактическому переходу отклонения; новый endpoint revise не добавлялся.

## Общие размеры и стили

По рассчитанным стилям браузера при ширинах 1427 и 390 px:

- Заголовки чернильные: rgb(12, 20, 37); пояснения приглушённые: rgb(98, 106, 123).
- Нижний отступ пояснения — 20 px.
- Заметки: отступ снаружи 18 px, внутри 16 × 18 px, прежняя светлая поверхность и скругление.
- В структуре на desktop три показателя располагаются в одном ряду; на телефоне переносятся.
- Строки расчётов: вертикальный padding 12 px, отступ после названия 5 px — как в макете страницы.
- Поле комментария: минимальная высота 76 px, светлая поверхность, подпись weight 500. Подсказки: «Что нужно уточнить или изменить?» для доработки; «Добавьте пояснение при необходимости» для остальных решений.
- Между действиями 10 px. Геометрия и состояния самих кнопок остаются общими Button, без отдельного местного радиуса, заливки или hover.
- Полный JSON открыт во всех десяти проверках; горизонтального выхода элементов согласования за viewport нет.
- Нижняя ссылка «Открыть в Synapse» сохраняет проверенный адрес, target=_blank и rel=noreferrer. Иконка и приглушённое оформление подтверждены на настоящей странице. Ссылка не открывалась и решение настоящего согласования не отправлялось.

## Проверки

Пять состояний проверены в браузере на компьютере и на ширине 390 px. Содержимое трёх исторических состояний и запроса взято из ранее прочитанных ответов Synapse; положительные калькуляторы — синтетический пример. Снимки compare-{manifest,ontology,calculators,empty,publish}-{desktop,mobile}.png и рассчитанные значения approval-comparison-final.json сохранены в каталоге визуализаций текущего чата.

Дополнительно выполнена проверка настоящего React-компонента через серверный рендеринг: предложение без названия, только с формулой; строковые и отсутствующие входы; вход с единицей и дополнительными границами; массив доступных единиц; причина с дополнительными полями; неструктурированная причина; пустые и отсутствующие ограничения; нулевые показатели охвата; расположение ограничений перед материалами. Исходные объекты после рендеринга не изменились. Проверка находится в исключённой из Git области .impeccable/review/approval-states.

Lint, production build, 15 тестов подготовки данных и ошибок, проверка форматирования, git diff --check и детектор Impeccable пройдены. Реальные решения и публикация не выполнялись. Проверка на физическом телефоне и отдельный прогон скринридером не проводились.

## Сохранённые отличия, прямо требуемые пользователем

Полный JSON заменяет сокращённые технические выдержки из первых макетов. Повторный вопрос и список документов убраны. Предпросмотр отчёта и готовые материалы не размножаются внутри согласования. Содержательные строки агента остаются дословными: демонстрационные причины, формулы и названия файлов из макетов не подставляются вместо реальных данных.
