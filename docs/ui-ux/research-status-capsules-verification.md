### 2. Конкретные предположения о дефекте

Первое: обычное обновление может заново запускать пульсацию в ResearchStatus.tsx:99. Опровергнуто сравнением идентичности точки после обновления: элемент тот же, активных анимаций ноль. При смене статуса элемент другой, активная анимация одна.

Второе: длинная подпись сожмёт капсулу или вытолкнет страницу вбок. В первом просмотре на desktop обнаружен преждевременный перенос короткой ошибки из-за flex-shrink. Добавлен flex-shrink: 0; после этого повторены все 12 проверок ширин, все статусы, анимации и контраст. Финальный снимок подтверждает одну строку ошибки при 1280 px и перенос длинных подписей при необходимости.

Третье: constructor / __proto__ вернут унаследованное значение словаря вместо текста. Для выбора подписи применяется Object.hasOwn, оба входа проверены в обоих экранах.
